# README Style Research / README 格式研究
## English
Reviewed primary upstream examples on 2026-10-06 UTC:
| Reference | Observed popularity | Pattern adopted |
| --- | --- | --- |
| [Playwright](https://github.com/microsoft/playwright) | ~97.1k stars in the consulted page | Short purpose, task-based start paths, examples and reference links |
| [Puppeteer](https://github.com/puppeteer/puppeteer) | ~95.7k stars in the consulted page | Separate prerequisites/installation from executable example and troubleshooting |
| [GitHub README guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes) | Official guidance | What, why, getting started, help and maintainers |
| [GitHub sensitive data guidance](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository) | Official guidance | Avoid leakage before publishing; history removal cannot recall all copies |

Star figures are mutable observations, not a quality guarantee. No implementation was copied. This repository uses English first, Chinese second; fenced language-tagged commands, compact tables, real relative document links, clear prerequisites and truthful validation limits. It avoids invented test badges, service logos and unmeasured performance promises. Source remains MIT; upstream references do not transfer their licences to this code.

## 简体中文
2026-10-06 UTC 查阅官方上游：Playwright 页面约 97.1k 星，Puppeteer 约 95.7k 星，并参考 GitHub README 与敏感数据文档。采用简短定位、按任务进入、前提与安装分离、执行示例、故障处理、帮助与许可证。

星数只是会变化的观察，不保证安全或质量；没有复制第三方实现。格式统一英文在前、中文在后，命令标注语言，表格清晰，相对文档链接真实，不制造测试徽章、品牌标识或未实测性能承诺。防止泄漏优于事后改历史，因为不能收回已经复制的内容。
