# Design and Documentation References

## English

These are layout and engineering references, not copied implementation or endorsement:

- [Playwright](https://github.com/microsoft/playwright): concise capability description, start paths, examples, reference links and contribution/security documents.
- [Crawlee](https://github.com/apify/crawlee): installation, usage, feature boundaries, documentation, contribution and license sections.
- [Electron quick start](https://github.com/electron/electron-quick-start-typescript): visible application entry points and reproducible local setup.
- [GitHub README guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes): project purpose, use, help and maintainers.
- [GitHub licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository): an explicit license, not merely a public repository.

Star counts change and are not a correctness or security guarantee. This project does not claim feature parity with the referenced tools.

星数会变化，不能证明正确性或安全性；本项目不宣称与参考工具具备相同能力。
