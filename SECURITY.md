# Security Policy

## English

Do not expose the control server or CDP endpoint to a network. Keep credentials, cookie imports, profiles and captured records outside version control. Use only applications and records you are authorized to access.

Report vulnerabilities through the repository's private vulnerability-reporting feature when available. Do not post secrets or private evidence in a public issue. If private reporting is unavailable, open an issue containing only a request for a private reporting channel.

This source release has synthetic tests and static release checks, not an independent security certification. Local locks, permissive asset subdomains, optional reviewer commands and raw evidence storage require care. Cookie import is optional, local and explicit; never share cookie files.

## 简体中文

控制服务和 CDP 端口不得暴露到网络。凭证、Cookie、浏览器配置和采集记录不得进入版本控制，仅访问有权使用的应用与记录。

优先通过仓库的私密漏洞报告功能提交问题，不把秘密或私有证据发到公开 Issue；若未开放私密入口，公开 Issue 仅用于请求私密沟通渠道。

本版本有合成测试和静态发布检查，没有独立安全认证。锁、资源子域、可选审查命令和原始证据存储仍需谨慎使用；Cookie 导入为明确的本地可选操作，不可分享 Cookie 文件。
